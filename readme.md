### 应用概览
- **应用名称**: 智投管家 (Intelli-Asset)
- **定位**: 面向个人投资者的全球股票资产管理与分析工具
- **支持市场**: A股、港股、美股
- **核心价值**: 录入与管理持仓、多币种汇总与转换、投资组合可视化与深度分析、历史快照与报告

### 目标用户与场景
- **个人投资者**：集中管理多市场持仓，查看总览与盈亏
- **多币种持仓用户**：统一换算为基准货币查看资产
- **数据爱好者**：查看分布、历史收益曲线、P&L 报告

### 支持平台与技术栈
- **平台**: iOS（iPhone / iPad）
- **UI**: SwiftUI，Apple Charts
- **数据**: 本地资源文件 `A-stock`、`HK-stock`、`US-stock`（内置股票清单与模拟价格）
- **持久化**: `UserDefaults`（持仓、汇率偏好、快照）
- **服务层**: 货币服务、分析服务、数据解析器、模拟行情 API

### 信息架构与导航
- **Tab 导航**（3 个标签页）：
  - **首页**：总览、图表、持仓列表、添加资产、下拉刷新
  - **分析**：总览/分布/历史/报告 四个子页签
  - **我的**：货币与汇率设置、数据管理、关于与支持

## 核心功能

### 1) 资产录入与管理
- **股票搜索**：按代码/名称快速搜索（内置模糊匹配、热门优先）
- **选择股票**：显示代码、名称、市场、当前模拟价格与涨跌幅
- **选择货币**：支持 CNY / HKD / USD，并给出市场默认推荐
- **输入持仓**：持股数量、平均成本价、购入日期
- **实时预览**：总成本、当前市值、预计盈亏金额与百分比
- **添加持仓**：保存后立即刷新该资产价格与更新深度分析
- **删除持仓**：列表行向左滑动删除
- **错误处理**：操作失败弹窗提示、清除错误

### 2) 首页（总览）
- **关键指标卡片**：
  - 总资产（基准货币）
  - 累计盈亏（金额与百分比，自动着色）
  - 总成本与持仓数量
- **资产分布图表**：
  - 市场分布（A/HK/US 饼图）
  - 货币分布（CNY/HKD/USD 饼图）
- **持仓列表**：
  - 展示名称、代码、市场标签、持股/成本/币种、购入日期
  - 右侧显示当前市值与盈亏百分比（红/绿）
  - 空态引导添加第一只股票
- **数据刷新**：
  - 下拉刷新全部价格
  - 应用内每 60s 自动刷新一次

### 3) 深度分析（四个分栏）
- **总览**：
  - 关键指标：总资产、总成本、持仓股票数、覆盖市场数
  - 时间范围选择：7天/1月/3月/6月/1年/全部
  - 回报率：总回报率、年化回报率
- **分布**：
  - 市场分布饼图（含图例）
  - 行业分布饼图（含图例，支持多行业）
  - 收益来源分布（柱状图，按行业聚合盈利贡献）
- **历史**：
  - 历史收益曲线（折线 + 面积图）
  - 历史统计（最高/最低/平均市值、数据点数）
- **报告**：
  - 盈亏报告列表：逐股盈亏金额与百分比，按盈利排序

### 4) 历史与快照
- **创建快照**：
  - 手动创建（分析页“快照”按钮）
  - 自动创建（页面出现或每日一次）
- **快照内容**：日期、总市值/总成本/总盈亏（基准货币）、各资产快照（含行业分类）
- **保留策略**：默认保留近 365 天
- **数据管理**（“我的”→数据管理）：
  - 查看快照数量与最近快照列表
  - 一键清除全部快照（带确认）

### 5) 设置（多币种与汇率）
- **基准货币**：选择 CNY / HKD / USD 作为汇总统计基准
- **汇率管理**：
  - 查看与编辑各币种之间汇率（双向自动更新）
  - 重置为默认汇率
- **金额格式**：统一格式化显示，必要时支持“原币种 + 基准币种”转换显示

### 6) 我的（Profile）
- **用户信息卡片**：昵称与说明
- **货币与汇率入口**：跳转到设置页面
- **数据管理**：快照管理、数据导出（预留）、联系支持（预留）
- **关于页面**：应用介绍、特性说明、版本信息

## 数据与模型
- `Asset`：持仓（代码、名称、市场、货币、数量、成本价、现价、购入日，派生市值/盈亏）
- `StockInfo`：搜索与报价实体（模拟当前价与涨跌幅）
- `MarketType`：`US`/`HK`/`CN`
- `CurrencyType`：`CNY`/`HKD`/`USD`（符号、显示名、默认市场）
- `ExchangeRate`、`CurrencyAmount`、`CurrencyPreferences`
- `PortfolioSnapshot`、`AssetSnapshot`：历史快照
- `IndustryType`：行业分类（科技、金融、消费等）
- `HistoryDataPoint`：历史曲线点

## 服务与逻辑
- `CurrencyService`
  - 偏好与汇率存储（`UserDefaults`）
  - 默认与自定义汇率、双向同步
  - 金额转换与格式化
  - 投资组合总值/总成本（按基准货币）计算、按货币聚合
- `StockDataParser`
  - 预加载本地资源（A/HK/US）
  - 代码标准化（A股去后缀、港股补零、美股去 .US）
  - 生成稳定的基础价格 + 随机波动（模拟）
  - 搜索/匹配得分/热门加权
- `StockAPIService`（`MockStockAPIService` 实现）
  - 搜索、单只与批量价格获取（基于本地数据 + 随机波动，模拟网络延迟）
- `PortfolioAnalysisService`
  - 快照生成与存储、历史范围筛选
  - 历史收益率数据点、总回报率、年化回报率
  - 市场/行业/收益来源分布
  - 行业映射（内置典型代码清单）
- `PortfolioViewModel`
  - 资产列表增删改、持久化
  - 批量/单只价格刷新、自动定时刷新
  - 聚合与分布计算（与 `CurrencyService` 协同）
  - 错误状态与 UI 绑定

## 交互与体验
- **刷新机制**：下拉刷新与 60s 自动刷新
- **触感反馈**：轻/中/重/成功/错误
- **错误处理**：弹窗提示、清除错误
- **空态引导**：未添加资产时的行动引导
- **自适应**：卡片式布局与列表组合，iPhone/iPad 友好

## 可视化
- **图表类型**：饼图（分布）、折线 + 面积（历史曲线）、柱状图（收益来源）
- **颜色语义**：市场/行业配色、盈亏红绿

## 多币种与汇率
- **基准货币统一**：CNY/HKD/USD 任一
- **转换细节**：默认汇率可重置，可手动覆盖；显示支持“原币种 + 基准”组合

## 支持市场与行业映射
- **市场**：A股/港股/美股，带交易所说明
- **行业分类**：基于典型代码映射（可扩展）

## 持久化与性能
- **数据**：`UserDefaults` 轻量持久化（持仓、偏好、快照）
- **启动优化**：应用启动预加载股票清单
- **列表/图表**：懒加载与轻量数据结构

## 隐私与安全
- **本地优先**：数据仅存本地（无账号系统）
- **网络**：当前行情为本地模拟，后续可换真实 API

## 已知限制与后续计划
- **行情数据**：当前使用模拟价格；后续接入真实行情 API
- **行业映射**：基于典型清单，建议引入更精细的行业分类源
- **数据导出/支持**：功能入口已预留，后续补全
- **多资产类型**：当前聚焦股票，后续可扩展基金、加密资产等

### 主要使用路径（示例）
1. 首页右上角“+”→ 搜索并选择股票 → 选择货币 → 输入数量/成本/购入日 → 预览 → 添加。
2. 首页下拉刷新全局价格，或等待自动刷新。
3. 切换到“分析”查看总览/分布/历史/报告，必要时“快照”。
4. “我的”→“设置”选择基准货币、管理汇率；“数据管理”查看/清除快照。
