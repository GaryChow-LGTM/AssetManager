# 股票搜索功能使用说明

## 🎉 新功能特性

现在应用已集成超过**10,000+**只真实股票数据：
- **A股**: 5,000+ 只股票
- **港股**: 2,600+ 只股票  
- **美股**: 3,000+ 只股票

## 🔍 智能搜索功能

### 支持的搜索方式

#### 1. 股票代码搜索
- **A股示例**: `600519`、`000001`、`300750`
- **港股示例**: `00700`、`09988`、`01398`
- **美股示例**: `AAPL`、`MSFT`、`GOOGL`

#### 2. 公司名称搜索
- **中文名称**: `腾讯`、`苹果`、`贵州茅台`
- **英文名称**: `Apple`、`Microsoft`、`Google`
- **部分匹配**: `银行`、`保险`、`科技`

#### 3. 关键词搜索
- **行业关键词**: `银行`、`医药`、`汽车`
- **地区关键词**: `贵州`、`平安`、`中国`

### 搜索优先级

系统会按以下优先级排序搜索结果：

1. **代码完全匹配** - 最高优先级
2. **代码前缀匹配** - 高优先级  
3. **名称完全匹配** - 高优先级
4. **名称前缀匹配** - 中等优先级
5. **热门股票** - 额外加分
6. **其他匹配** - 普通优先级

### 搜索示例

| 搜索词 | 匹配结果示例 |
|--------|------------|
| `600519` | 贵州茅台 (代码完全匹配) |
| `腾讯` | 腾讯控股 (名称匹配) |
| `AAPL` | 苹果公司 (代码完全匹配) |
| `银行` | 工商银行、建设银行、平安银行... |
| `科技` | 科技类股票列表 |

## 📊 数据特性

- **实时价格模拟**: 基于股票代码生成一致的价格
- **价格波动**: ±5%的随机波动模拟真实市场
- **智能排序**: 热门股票优先显示
- **快速搜索**: 支持50条结果快速加载

## 🚀 使用建议

1. **精确搜索**: 输入完整股票代码获得最精确结果
2. **模糊搜索**: 输入公司名称关键词发现相关股票
3. **行业搜索**: 使用行业关键词找到同类股票
4. **热门推荐**: 搜索常见词汇时会优先显示热门股票
